Data sources & attribution

Measured speeds come from public benchmark data, credited here. Data generated 2026-10-14. 630 measured rows used; 119 (hardware, model, quant) data points across 20 hardware entries.

  • LocalScore (Mozilla Builders / cjpais, Apache-2.0)
  • llama.cpp community benchmark threads (ggml-org/llama.cpp, MIT)
  • Hugging Face / GitHub open-licensed benchmark repos (see data/benchmarks/README.md)

LocalScore results are community-submitted averages published on localscore.ai (open-source project, Apache-2.0, by Mozilla Builders / Justine Tunney's llamafile team and cjpais). Only public pages were read, at a low request rate. This site is not affiliated with LocalScore or Mozilla.

How "measured" and "estimated" work

efficiency = measured_tg / (memory_bandwidth_GBps / read_GB); dense models only; read_GB = params*bits_per_weight/8 >= 3.0 GB; single-device; median; per-hardware factor needs >= 3 rows, else per-kind median, else the global assumption. Global default efficiency before calibration: 0.55.
