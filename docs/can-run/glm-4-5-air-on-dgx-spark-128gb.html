FAQ

How fast is GLM-4.5-Air on NVIDIA DGX Spark 128GB?

About 17.1 tokens/s for generation (Q4_K_M, estimated from 273 GB/s memory bandwidth). Speed drops as the context fills; see the depth table on this hardware's other pages.

How much memory does GLM-4.5-Air need on NVIDIA DGX Spark 128GB?

The advisor's pick, Q4_K_M, is 73.0 GB of weights plus 3.09 GB of KV cache at 16k context (76.1 GB), against 108.3 GB usable.

Is the GLM-4.5-Air speed on NVIDIA DGX Spark 128GB measured or estimated?

Estimated. No measured llama.cpp run for this pair is on file yet, so the figure comes from memory bandwidth and our calibration against measured hardware.

What can I use instead of NVIDIA DGX Spark 128GB for GLM-4.5-Air?

With less memory, Mac Studio M5 Max 128GB (~33 tok/s), MacBook Pro 14/16 M5 Max 128GB (~33 tok/s), MacBook Pro 14/16 (2024) M4 Max 128GB (~22 tok/s) also fit it fully. Faster: RTX PRO 6000 96GB (~121 tok/s), Mac Studio M5 Ultra 256GB (~46 tok/s), Mac Studio M5 Ultra 512GB (ships late Oct 2026) (~46 tok/s).

What is the maximum context for GLM-4.5-Air on NVIDIA DGX Spark 128GB?

With an f16 KV cache about 128k tokens, 128k with q8_0 and 128k with q4_0, bounded by the model's own limit.
