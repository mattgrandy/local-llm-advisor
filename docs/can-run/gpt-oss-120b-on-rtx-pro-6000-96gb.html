Can RTX PRO 6000 96GB run gpt-oss 120B?

Measured results for gpt-oss 120B (116.83B MoE, 5.1B active) on RTX PRO 6000 96GB, plus what fits and the commands to run it.

Short answer

Yes. gpt-oss 120B Q8_0 fits fully on RTX PRO 6000 96GB at 16k context, using 64.0 of 95.0 GB usable, and generates about 260.8 tokens/s in our own run. As the context fills it slows down: 231.4 tok/s with 16k tokens already in context (89% of the empty-context speed), measured. For Q8_0, our bandwidth-only estimate was ~356 tok/s against a measured median of ~261 (37% too optimistic).

FAQ

How fast is gpt-oss 120B on RTX PRO 6000 96GB?

About 260.8 tokens/s for generation (Q8_0 on llama.cpp CUDA, 128-token generation), 9342 tokens/s for prompt processing. Speed drops as the context fills; see the depth table.

How much memory does gpt-oss 120B need on RTX PRO 6000 96GB?

The advisor's pick, Q8_0, is 63.4 GB of weights plus 0.61 GB of KV cache at 16k context (64.0 GB), against 95.0 GB usable.

Is the gpt-oss 120B speed on RTX PRO 6000 96GB measured or estimated?

Measured: our own llama-bench run on a rented RTX PRO 6000 Blackwell Workstation, including runs with 4k to 16k tokens already in context.

What can I use instead of RTX PRO 6000 96GB for gpt-oss 120B?

With less memory, Mac Studio (2025) M3 Ultra 96GB (~92 tok/s), Mac Studio M5 Max 128GB (~107 tok/s), MacBook Pro 14/16 M5 Max 128GB (~107 tok/s) also fit it fully.

What is the maximum context for gpt-oss 120B on RTX PRO 6000 96GB?

With an f16 KV cache about 128k tokens, 128k with q8_0 and 128k with q4_0, bounded by the model's own limit.
