FAQ

How fast is Mistral Small 3.2 24B on 16GB VRAM class (RTX 4060 Ti 16GB, 32GB RAM)?

About 19.1 tokens/s for generation (Q4_K_M on llama.cpp CUDA, 128-token generation), 1206 tokens/s for prompt processing. Speed drops as the context fills; see the depth table.

How much memory does Mistral Small 3.2 24B need on 16GB VRAM class (RTX 4060 Ti 16GB, 32GB RAM)?

The advisor's pick, Q4_K_M, is 14.3 GB of weights plus 2.68 GB of KV cache at 16k context (17.0 GB), against 15.0 GB usable.

Is the Mistral Small 3.2 24B speed on 16GB VRAM class (RTX 4060 Ti 16GB, 32GB RAM) measured or estimated?

Measured: our own llama-bench run on a rented GeForce RTX 4060 Ti 16GB, including runs with 4k to 4k tokens already in context.

What can I use instead of 16GB VRAM class (RTX 4060 Ti 16GB, 32GB RAM) for Mistral Small 3.2 24B?

It needs more memory than this hardware has; Mac mini M6 32GB, MacBook Air M5 32GB, RTX 3090 24GB fit it fully. Faster: RTX 4090 24GB (~46 tok/s), RTX 3090 24GB (~39 tok/s), AMD RX 7900 XTX 24GB (~30 tok/s).

What is the maximum context for Mistral Small 3.2 24B on 16GB VRAM class (RTX 4060 Ti 16GB, 32GB RAM)?

It does not fit fully in GPU memory, so context is bounded by offload, not by this table.
