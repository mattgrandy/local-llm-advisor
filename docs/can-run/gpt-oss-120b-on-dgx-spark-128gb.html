Short answer

Yes. gpt-oss 120B Q8_0 fits fully on NVIDIA DGX Spark 128GB at 16k context, using 64.0 of 108.3 GB usable, and generates about 56.8 tokens/s. For Q8_0, our bandwidth-only estimate was ~54 tok/s against a measured median of ~57 (4% too pessimistic).

FAQ

How fast is gpt-oss 120B on NVIDIA DGX Spark 128GB?

About 56.8 tokens/s for generation (Q4 class, median of 6 public runs). Speed drops as the context fills; see the depth table on this hardware's other pages.

How much memory does gpt-oss 120B need on NVIDIA DGX Spark 128GB?

The advisor's pick, Q8_0, is 63.4 GB of weights plus 0.61 GB of KV cache at 16k context (64.0 GB), against 108.3 GB usable.

What is the maximum context for gpt-oss 120B on NVIDIA DGX Spark 128GB?

With an f16 KV cache about 128k tokens, 128k with q8_0 and 128k with q4_0, bounded by the model's own limit.
