FAQ

How much VRAM does Qwen3.8 Flash Next need?

The smallest quant (Q4_K_M) is 111.33 GB, so you need roughly 113 GB for an 8k context including KV cache and overhead. At 256k context the f16 KV cache alone is 6.6 GB.

Can I run Qwen3.8 Flash Next on a Mac Studio M5 Ultra 256GB?

Yes: on Mac Studio M5 Ultra 256GB it fits fully as UD-Q5_K_XL at about 111 tok/s (estimated). 3 of 28 hardware configurations fit it fully at 16k context.

What is the maximum context for Qwen3.8 Flash Next?

256k tokens natively. Memory, not the model, is usually the limit: see the KV cache table above.
