FAQ

How much VRAM does Qwen3.6 35B-A3B need?

The smallest quant (Q4_K_M) is 22.13 GB, so you need roughly 23 GB for an 8k context including KV cache and overhead. At 1M context the f16 KV cache alone is 20.5 GB.

Can I run Qwen3.6 35B-A3B on a RTX PRO 6000 96GB (bonus page)?

Yes: on RTX PRO 6000 96GB (bonus page) it fits fully as Q8_0 at about 281 tok/s (estimated). 16 of 26 hardware configurations fit it fully at 16k context.

What is the maximum context for Qwen3.6 35B-A3B?

256k tokens natively, up to 1.01M with YaRN as documented on the model card. Memory, not the model, is usually the limit: see the KV cache table above.
