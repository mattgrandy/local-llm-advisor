FAQ

How much VRAM does gpt-oss 20B need?

The smallest quant (Q4_K_M) is 11.62 GB, so you need roughly 13 GB for an 8k context including KV cache and overhead. At 128k context the f16 KV cache alone is 3.2 GB.

Can I run gpt-oss 20B on a RTX PRO 6000 96GB?

Yes: on RTX PRO 6000 96GB it fits fully as Q8_0 at about 376 tok/s (measured). 24 of 29 hardware configurations fit it fully at 16k context.

What is the maximum context for gpt-oss 20B?

128k tokens natively. Memory, not the model, is usually the limit: see the KV cache table above.
