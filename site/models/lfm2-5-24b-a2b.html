FAQ

How much VRAM does LFM2.5 24B-A2B need?

The smallest quant (Q4_K_M) is 14.53 GB, so you need roughly 16 GB for an 8k context including KV cache and overhead. At 128k context the f16 KV cache alone is 2.7 GB.

Can I run LFM2.5 24B-A2B on a RTX 5090 32GB?

Yes: on RTX 5090 32GB it fits fully as Q8_0 at about 343 tok/s (scaled from measured). 23 of 28 hardware configurations fit it fully at 16k context.

What is the maximum context for LFM2.5 24B-A2B?

128k tokens natively. Memory, not the model, is usually the limit: see the KV cache table above.
