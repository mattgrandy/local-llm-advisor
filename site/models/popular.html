Method and sources

Score = Hugging Face downloads over the last 30 days for the original repo plus its plain GGUF conversions from unsloth, bartowski, ggml-org, lmstudio-community and the model maker's own GGUF repo. Likes and Ollama library downloads (all-time, per model family) are shown for context and are not part of the score. The Hugging Face number is the API's downloads field, which model pages show as "Downloads last month". How the Hub counts them (every request to a counted file, including each GGUF file, so whole-repo clones count more than once) is described in the HF download-stats docs. Every number links to the repo it came from. Ollama counts come from each ollama.com library page; they are all-time and shared by every size in a family (for example all DeepSeek R1 distills share one count), so they are shown for context only. Download counts include automated pulls and CI, so read the ranking as relative demand, not users. Candidates are the site's models plus other popular open-weight models we considered; models above about 250B parameters or without GGUF files are not added to the site.
