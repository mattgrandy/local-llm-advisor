MLX on this Mac

MLX is Apple's machine-learning framework for Apple Silicon. Where an mlx-community conversion exists, the commands above include an MLX block next to llama.cpp and ollama.

  • File size. MLX's default quantization is affine with a group size of 64, and every group stores a scale and a bias (MLX docs). With 16-bit scales and biases that works out to about 4.5 bits per weight at 4-bit and 8.5 at 8-bit. llama.cpp lists Q4_K_M at about 4.89 and Q8_0 at about 8.50 bits per weight (llama.cpp quantize README). So an MLX 4-bit repo is usually a little smaller than Q4_K_M and MLX 8-bit is about the same size as Q8_0. Real repos differ because some layers (embeddings, vision towers, MoE experts in MXFP4 for gpt-oss) are stored differently, so we show each repo's actual size.
  • Quality. They are different schemes. MLX 4-bit applies one bit width with per-group scale and bias, while Q4_K_M is a K-quant mix that keeps some tensors at higher precision (llama.cpp k-quants PR). We have not found a rigorous like-for-like quality comparison, so we only pair them by bit class: MLX 4-bit with Q4-class GGUF and MLX 8-bit with Q8_0.
  • Speed. MLX speeds are not shown on this site yet. Published comparisons often find MLX faster than llama.cpp on Macs: an M2 Ultra study measured about 230 tok/s for MLX against about 150 for llama.cpp (short context) on Qwen-2.5 models (arXiv 2511.05502), and an M4 Max table shows mlx-lm ahead of llama.cpp on most 4-bit text models but behind on Gemma 3 4B (arXiv 2601.19139). So MLX may well run faster than the llama.cpp numbers shown here, but not for every model, and we do not estimate by how much.
  • Which package. Text-only conversions run with mlx-lm. Many recent mlx-community repos (Gemma 4, Qwen3.5/3.6/3.8, Qwen3-VL) were converted with mlx-vlm and their model cards say to run them with it, so the command we show follows each repo's card.

FAQ

How fast is Qwen3.5 9B on Mac mini / iMac M4 16GB?

About 13.8 tokens/s for generation (Q4_K_M, estimated from 120 GB/s memory bandwidth). Speed drops as the context fills; see the depth table on this hardware's other pages.

How much memory does Qwen3.5 9B need on Mac mini / iMac M4 16GB?

The advisor's pick, Q4_K_M, is 5.7 GB of weights plus 0.59 GB of KV cache at 16k context (6.3 GB), against 10.7 GB usable.

Is the Qwen3.5 9B speed on Mac mini / iMac M4 16GB measured or estimated?

Estimated. No measured llama.cpp run for this pair is on file yet, so the figure comes from memory bandwidth and our calibration against measured hardware.

What can I use instead of Mac mini / iMac M4 16GB for Qwen3.5 9B?

With less memory, 8GB VRAM class (RTX 4060 8GB, 32GB RAM) (~46 tok/s) also fit it fully. Faster: RTX 5070 12GB (~68 tok/s), RTX 4070 12GB (~51 tok/s), RTX 3060 12GB (32GB RAM) (~37 tok/s).

What is the maximum context for Qwen3.5 9B on Mac mini / iMac M4 16GB?

With an f16 KV cache about 128k tokens, 256k with q8_0 and 512k with q4_0, bounded by the model's own limit.
